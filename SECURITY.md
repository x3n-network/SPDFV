# Security

SPDFV is not yet distributed as a supported public release.

Please do not post exploitable document samples or private PDFs in a public issue. Report security-sensitive problems privately to the repository owner through GitHub’s private vulnerability reporting once the repository is public.

Include the affected commit or version, macOS version, reproduction steps, and a minimal non-sensitive sample when possible. Issues involving sandbox escapes, unintended file access, hidden-content leakage after redaction, or unsafe handling of malformed PDFs should be treated as security reports.
