# SPDFV compatibility corpus

These small, non-sensitive PDFs are checked in so compatibility behavior is exercised against stable bytes rather than only fixtures produced during the current test run.

Every file is original project test data generated by `Scripts/generate_compatibility_corpus.swift`; it contains no third-party content or personal information. The fixtures are distributed under the repository's MIT License. `manifest.json` records the expected facts asserted by the integration suite.

PDFKit refreshes internal document identifiers and encryption salts when regenerating these files, so regenerated PDFs are semantically reproducible but not guaranteed to be byte-for-byte identical. The committed bytes remain the compatibility baseline; review fixture changes through the manifest-backed tests.

- `mixed-layout.pdf` covers portrait and landscape media boxes, inset crop boxes, rotation, metadata, and annotations.
- `interactive-form.pdf` covers named text and checkbox widgets with saved values.
- `locked.pdf` covers encrypted-document preflight without embedding a private document. Its public test-only user password is `fixture-password`.

Regenerate from the repository root, then run the CLI integration suite and review the binary diff:

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift Scripts/generate_compatibility_corpus.swift
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  swift test --package-path CLI
```
